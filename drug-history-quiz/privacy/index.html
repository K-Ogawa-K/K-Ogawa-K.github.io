1. アプリ内に保存するゲーム情報

本アプリはアカウント登録を設けていません。プレイ回数、回答数、正解数、最高スコア、最大コンボ、獲得経験値、獲得した薬カードと年代別達成状況、および保存重複を防ぐための直近最大128件のプレイ識別子を、端末内のアプリ保存領域に保存します。個々の回答履歴や氏名、メールアドレスをゲーム進捗として記録する機能はありません。

全画面広告を90秒以上の間隔で表示するため、最後に表示した時点の端末起動後経過時間も端末内に保存します。この値は広告事業者や運営者のサーバーへ送信しません。端末を再起動して経過時間を安全に比較できない場合は、短い間隔で広告を出さないよう90秒の間隔を取り直します。

これらのゲーム進捗を運営者のゲーム用サーバーへ送信する機能はありません。クイズの薬データはアプリに同梱しています。薬名や回答内容を個別広告のターゲティング情報として広告リクエストへ追加しません。

アプリを削除すると、通常は端末内のゲーム進捗も削除されます。端末バックアップからアプリデータを復元した場合は、バックアップに含まれる進捗が戻ることがあります。

2. 広告と第三者SDK

本アプリは広告の表示にGoogle Mobile Ads SDK、広告に関するプライバシー選択の管理にGoogle User Messaging Platform（UMP）SDKを使用します。広告が表示される場合、GoogleのSDKが広告配信、効果測定、不正防止、サービス運用のために情報を処理することがあります。

Google Mobile Ads SDKのプライバシーマニフェストには、概算位置情報、広告データ、アプリ内の操作情報、端末識別子、クラッシュ情報、性能情報、その他の診断情報が記載されています。このうち端末識別子は、トラッキングに使用するデータとして申告されています。UMP SDKのマニフェストには、概算位置情報、性能情報、アプリ内の操作情報がアプリ機能のためのデータとして記載されています。GoogleのSDKはIPアドレス等から概算位置を推定する場合があります。実際の処理は、SDKの版、地域、UMPでの選択、ATTの状態、広告リクエストおよびGoogleの設定によって異なります。

  • Google Mobile Ads SDK のiOSデータ開示：Google Developers
  • Googleの広告配信モード：Google Developers
  • UMPのIDFA説明とATT：Google Developers
  • Googleのプライバシーポリシー：Google
  • 制限付き広告とProgrammatic Limited Ads：Google AdMob

3. 同意と広告の選択

アプリ起動時にUMPで同意情報を更新し、設定上必要な場合にプライバシー選択画面を表示します。アプリはUMPが広告リクエストを許可すると確認した場合に限って広告を要求します。必要な同意や配信要件を満たさず、許可される広告がない場合は広告を要求しません。

AdMobでIDFAメッセージが設定され、端末でATTをまだ選択していない場合は、UMPの説明画面に続いてiOSのATTシステムダイアログが表示されることがあります。ATTは一度選択すると、通常はiOSの設定で変更するまで同じシステムダイアログは再表示されません。アプリはiOSのトラッキング要求設定とATTの選択状態を確認します。ATTでトラッキングが許可されていない場合、アプリは非パーソナライズ広告を指定して広告を要求します。広告の種類（パーソナライズ、非パーソナライズ、制限付き）は、地域ごとの規制、UMPの目的・広告事業者への同意、およびGoogleの配信条件に従います。Googleの条件を満たす広告がない場合は広告が表示されないことがあります。UMPが広告リクエストを許可しない場合、アプリはリクエスト自体を行いません。広告を拒否した場合も、すべてのゲームモードとゲーム進捗を利用できます。

UMPがアプリ内のプライバシー選択肢を必要と判断した場合、ホーム画面に「広告のプライバシー設定」が表示されます。ATTの選択はiOSの「設定」から変更できます。変更がアプリへ反映されると、アプリは広告の許可状態を再確認します。

非パーソナライズ広告でも、配信頻度の制御や集計レポートなど、Googleが説明する目的で識別子等が処理される場合があります。非パーソナライズ広告を、識別子を一切使わない広告とは説明していません。

GoogleのTCF要件では、該当地域で非パーソナライズ広告を配信する場合も、端末上の情報の保存・アクセスに関する目的1の同意が必要です。ATTの状態だけで広告の許可が決まるものではありません。パーソナライズ広告、非パーソナライズ広告、制限付き広告のいずれも地域の規制、UMPの選択、Googleの配信条件を満たさない場合、広告は要求または表示されないことがあります。

TCFの選択でパーソナライズ広告と非パーソナライズ広告を利用できない場合、Google Mobile Ads SDKが制限付き広告を試みるのは、Googleベンダーへの必要な透明性があり、特別目的1・2が許可されている場合に限られます。GoogleのProgrammatic Limited Ads（PLA）が有効な場合、同意の有無を問わない不正トラフィック検出のためCookieやローカルストレージを使う場合があります。実際の広告配信はAdMobアカウント設定と地域の要件に従います。

4. 保存期間と削除・選択の変更

ゲーム進捗は、端末内で利用している間保存されます。利用者はアプリを削除して端末内のゲーム進捗を削除できます。Googleの広告関連情報の保存、閲覧、削除、広告設定の手続きは、Googleが提供するマイ アド センターおよびプライバシーポリシーをご確認ください。

同意・広告プライバシーの選択は、前項に記載したアプリ内の設定導線またはiOSの設定から変更できます。アプリ内のゲーム進捗についてお問い合わせがある場合は、下記の窓口へご連絡ください。
